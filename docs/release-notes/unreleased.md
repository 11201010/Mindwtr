# Mindwtr Unreleased

Changes collected since the latest stable release.

## Full Change List

- Someday projects can now sit in Someday sections. When Someday is grouped by section, each parked project shows inside its section, above that section's tasks, instead of in the Projects block at the top. Use **Move to section…** on the project row (desktop button; long press on mobile) to place it. The project keeps its area, sections, tasks and notes. Reactivating it keeps its section, so parking it again puts it back. A deleted section's projects move to "No section". (#1319)
