# Mindwtr 1.3.0

Mindwtr 1.3.0 expands capture and widgets, makes project outcomes more precise, and strengthens sync, editing, review, and recovery across desktop and mobile.

## Highlights

- Cancel tasks, projects, and recurring series while keeping completed and cancelled outcomes distinct in Archive. Sequential projects now follow the visible manual order of sections and tasks.
- Capture without opening the full app through Android widgets, Quick Settings, app shortcuts, and notifications. Apple Watch adds text and audio capture, task actions, and Pomodoro controls.
- Android gains native, interactive task widgets, while iPhone and iPad gain configurable interactive Focus and Compact widgets with saved-filter support.
- WebDAV, File Sync, Dropbox, iCloud, and self-hosted sync handle more proxy, attachment, lifecycle, and recovery cases without losing work.
- Focus, Inbox processing, Reference, Review, task editing, project creation, and selected-task CSV export now cover more of the workflow in place.
- Desktop and mobile use less repeated work during sync, search, settings, widgets, calendars, and persistence, with stronger checks around durable native actions.
- Self-hosted capture supports restricted capture-only tokens, and MCP gains safer attachment handling plus the updated task and project lifecycle fields.
- Thanks to [@alangrainger](https://github.com/alangrainger) and [@svanati](https://github.com/svanati) for supporting the project.

## Tasks and projects

- **Cancel task**, **Cancel project**, and **Cancel recurring series** preserve work you chose not to continue without counting it as completed. Cancelled items remain searchable in Archive, and project reactivation restores eligible actions.
- Sequential projects follow the manual hierarchy shown with Default sorting: section order, task order within each section, then No Section. Display sorting does not change the sequence.
- Finishing a project is now called **Complete**. Completed and cancelled projects appear as separate outcomes under **Closed**.
- The quick action on a Waiting For task marks it Done. The status menu still offers Next when responsibility returns to you.
- Desktop task menus and bulk organization can create a project or area without discarding the current form or selection.
- Quick Inbox processing can create several next actions when an item becomes a project.
- Project sections remain available in task editors, and upgraded devices converge on the same task-editor layout.
- Archived project reference material and section relationships survive restart, sync, cancellation, and reactivation.
- Mobile cancellation saves the current draft, including notes and attachments, before closing the editor.
- Desktop can edit a task's completion time from the Done list again.

## Capture and automation

- Android's widget button, Quick Settings tile, app shortcut, and capture notification open a small native capture window over the current screen. Saving or cancelling returns to the previous app.
- Android automation can send text to a protected explicit broadcast receiver after the user enables Automation capture and copies its local token.
- Native Android quick capture can record audio when speech-to-text is enabled. Pending recordings remain available after a failed transcription or save.
- Shortcut and Action Button capture on iPhone opens one confirmation form per delivery on cold and warm launches.
- iOS share capture has a privacy-safe diagnostic trail for host routing, payload preparation, form mounting, and save results.
- The app acknowledges native capture, completion, defer, and widget commands after durable storage accepts them; failed saves remain retryable.
- Similar-task suggestions appear during Inbox processing to help spot possible duplicates without blocking or merging anything.
- The sample-data sandbox provides an isolated workspace for private bug recordings without touching personal data or sync.

## Focus, review, and reference

- Focus can collapse everything except Today's Focus while keeping each section heading and count available.
- Today's later-starting tasks appear under **Later today** until their start time.
- Saved Focus filters toggle off when selected again, and mobile supports long-press deletion with a screen-reader action.
- Android widgets and iOS widgets follow the app's Focus filters, saved filters, area, and sort order.
- Weekly Review can create a local share card with a privacy-first summary and an offline-safe QR destination.
- Mobile Review keeps Inbox and completion controls reachable in short windows and nested modal flows.
- Reference browsing and search are simpler, include archived-project material when requested, and refresh cached hits from current entities.
- Reference checklists stay inside the full task preview instead of expanding in mobile task rows, remain editable as lists on desktop and mobile, and keep focus and the keyboard visible when Android inserts a row.
- Inbox processing uses Contexts terminology consistently and gives Clarify, Do, Delegate, Defer, and Reference equal visual emphasis.
- Sync summaries use localized task, project, area, and section labels.

## Widgets and Apple Watch

- Android Tasks widgets are native, scrollable, resizable, and configurable for Focus, Inbox, Next Actions, Waiting For, Someday/Maybe, or a saved filter.
- Android widget rows show priority, project or area, due information, and an interactive completion ring with undo support. Tapping a task opens a native detail card.
- Android also includes one-cell Quick capture and smaller Compact widgets, with lock-screen support where Android offers it.
- iOS Tasks widgets come in system-supported sizes, can select a built-in list or saved filter, and support queued task completion on iOS 17 and later.
- iOS Compact widgets provide a denser flat Focus list without interactive rings.
- Apple Watch shows the phone's Focus snapshot and Pomodoro state, and can complete, defer, or start timer actions through the phone's durable queue.
- Apple Watch text and audio captures survive connectivity and outbox-save failures and can be resent without replacing pending work.
- Widget publication derives all iOS families from one task snapshot and preserves terminal task outcomes when late actions arrive.

## Sync, storage, and attachments

- Desktop WebDAV sync works behind proxies that rewrite compressed responses and ETags, avoiding repeated remote-write conflicts.
- WebDAV attachment activation checks large libraries in bounded batches and retries incomplete presence proofs instead of caching a failed result.
- File Sync streams attachments with safer file permissions and accepts a document whose attachment files have not reached the folder yet.
- Mobile File Sync retains missing attachment references during activation so Syncthing or another folder provider can deliver the files later.
- iCloud recreates a user-deleted CloudKit zone, resets its change token, reads the zone, and uploads the device's data again.
- Project lifecycle fields are normalized before merge so archive, cancellation, and Focus state converge across clients.
- Task-editor layout settings converge across upgraded devices without overwriting an explicit layout with migration defaults.
- Mobile uses one safely reconciled automatic background-sync schedule for every configured supported backend, including devices whose old interval preference was Off.
- Cloud validates attachment payloads before persistence and recovers usable file and link records from legacy or malformed data.
- Dropbox OAuth callback reads use bounded blocking behavior on macOS and other BSD systems.
- Archived outcomes remain intact when a delayed widget or Watch action reaches the app.
- SQLite can remove the final expired tombstones after verifying that no live entity would be lost.
- Android backup export writes through the selected system document provider.
- Attachment rows stay contained in desktop task editors, including long file names and narrow windows.

## Desktop

- Selected tasks can be exported to CSV from bulk selection, including filtered Context views.
- Project notes support Tab and Shift+Tab indentation, and their preview preserves nested lists.
- Calendar timed blocks use a light project or area tint with a colored leading bar.
- Today keyboard navigation follows the visible grouping order.
- Project and area creation is available from task quick actions and bulk organization.
- The task editor groups fields into clearer sections and keeps custom field ordering synchronized.
- The feedback form is more compact, and opt-in diagnostics retain recent sanitized warnings and errors even when persistent debug logging is off.
- Project menus stay above sticky toolbars, Timeline uses an area's color when a project has no custom color, and navigation keeps page geometry stable.
- Notification toasts pause while hovered or keyboard-focused and use opaque backgrounds for readability.
- KDE Plasma matches the running app to the pinned launcher without creating a second entry.
- macOS packages include the Swift runtime needed by Intel and Apple silicon builds, while widget and App Intents metadata receive release-time validation.

## Mobile

- Android navigation adapts to compact, expanded, book, and tabletop windows from reported window and hinge geometry, with no device-specific mode.
- Task editors and Quick Capture preserve active drafts and focus through same-process Android Activity recreation.
- Android label measurement updates after a system font-size change, preventing clipped dates, counts, chips, and buttons.
- Failed mobile captures announce the localized failure to TalkBack after the error appears.
- Quick capture serializes overlapping submissions, keeps route ownership until saving ends, and leaves the form available for retry.
- Dropbox authorization returns to Sync settings after the native callback instead of leaving the app on an unrelated screen.
- Mobile task details use spacing instead of separator dots, so wrapped lines do not start with stray punctuation.
- Reference lists stay in the task preview instead of expanding every item in task rows, and the feedback form uses less vertical space.
- iOS widget configurations are split by OS availability so older supported systems receive compatible intents.
- Mobile project and task editors keep section fields visible in saved layouts.

## Self-hosted server and MCP

- Self-hosted servers can issue, list, and revoke capture-only tokens that authorize `POST /v1/capture` without granting data read or write access elsewhere.
- Self-hosted voice capture stores audio at the attachment path clients expect and no longer adds the sender's client label to the task description.
- Failed self-hosted capture writes retain audio whenever deleting it could remove data already referenced by the canonical document.
- Cloud task writes apply the same Focus eligibility and limit rules as the apps.
- MCP local and cloud tools support cancellation and the current task, project, section, and attachment fields.
- MCP attachment replacement rejects encoded network-share paths after decoding while allowing unchanged legacy links to remain.
- MCP installation guidance covers supported Node versions and approval for native npm dependencies.

## Accessibility and languages

- Mobile capture errors have an explicit TalkBack announcement, and saved-filter deletion is available as a screen-reader action.
- Review controls, editor actions, widgets, and task rows preserve accessible labels and actions across their updated flows.
- Hungarian joins the app's supported languages.
- Simplified and Traditional Chinese settings use corrected Automation and Rendering terminology.
- Simplified and Traditional Chinese, German, Spanish, French, and other translations receive updated project, lifecycle, sync, widget, and review terms.

## Performance and reliability

- Desktop storage reuses SQLite statements, retains unchanged rows in append-only capture saves, and skips fingerprint work for snapshots equal by structure.
- Sync serialization reuses bounded property ordering and avoids copying merge winners whose attachments did not change.
- Search refreshes cached results from the current task and project entities instead of returning stale objects.
- Calendar push sync reads its mapping inventory once per full run instead of loading mappings per task.
- iOS widget families derive from one shared snapshot per publication.
- Desktop settings preserve content while lazy pages load, and benchmarks measure the native completion of saves and invokes.
- Android release benchmarks verify package identity, viewport, keyboard readiness, save completion, frame evidence, and SQLite fixture isolation.
- AI capture supports configurable request timeouts and stops retrying after terminal errors or cancellation.

## Packaging and release automation

- Stable iOS builds include the Apple Watch app, distribute the build through TestFlight, and submit the iOS version for App Review.
- Release candidates package the Watch app for TestFlight without submitting a production App Store version.
- Stable Windows builds produce a Microsoft Store package and can also submit the same signed binary to the configured beta flight.
- A recovery workflow can build a Microsoft Store flight package from the checksum-verified Windows binary of an existing release candidate.
- Windows standalone builds skip Store validation, declare x64 architecture, and avoid release concurrency deadlocks.
