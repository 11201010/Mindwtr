# Mindwtr 1.3.0-rc.1

This release candidate adds cancellation, sequential-project ordering, native Android widgets and system capture, an Apple Watch companion for TestFlight, and safer sync and self-hosted capture.

## Highlights

- Cancel tasks, projects, and recurring series while keeping a clear record in Archive. Upgrade every device and automation client before using cancellation because older versions do not understand the new state.
- Keep Focus and Next Actions in the visible manual order of sequential projects, including section order and unsectioned tasks.
- Use Android's native Tasks and Quick Capture widgets. Choose Focus, Inbox, Next Actions, Waiting For, Someday/Maybe, or a saved filter; complete tasks from the widget and capture without opening the full app.
- Test the new Apple Watch companion through TestFlight: review Focus, complete or defer tasks, control a Pomodoro timer, and capture text or audio for the phone to ingest.
- Create capture-only tokens on a self-hosted server and receive voice captures with their audio attachments intact.
- Get more reliable WebDAV, File Sync, and iCloud recovery, including compressed proxies, attachments that have not reached a shared folder yet, and a CloudKit zone cleared from iCloud settings.

## Reliability and compatibility

- WebDAV verifies the stored bytes and attachment presence before acting, while File Sync keeps missing attachment references until the file arrives.
- Cloud capture retains audio when document state is uncertain, and MCP updates preserve existing network links while rejecting new unsafe ones.
- Linux packages match pinned KDE Plasma launchers correctly, and desktop task editing, notes lists, project menus, Timeline colors, calendar blocks, and notification toasts are more reliable.
- Mobile task details, font-scale changes, Focus widgets, and system-entry capture return behavior are more consistent.

## Testing focus

- Upgrade all participating clients, then cancel and reactivate tasks and projects, stop a recurring series, and confirm completed and cancelled items remain distinct after sync.
- Reorder sections and tasks in a sequential project and confirm Focus, Next Actions, widgets, and synced devices follow the same manual hierarchy.
- On Android, place and resize both widgets, switch lists and saved filters, complete and undo tasks, open task details, and capture from the widget, Quick Settings, app shortcut, and notification.
- On TestFlight, pair the Watch app, send text and audio captures, complete and defer tasks, and exercise Pomodoro controls through disconnects and reconnects.
- Exercise WebDAV through a compressing proxy, join a File Sync folder before all attachments arrive, and clear then restore Mindwtr's iCloud data.
- For self-hosted Cloud, create, use, list, and revoke a capture-only token; submit text and audio captures and confirm the attachment reaches another client.
