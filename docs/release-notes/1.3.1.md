# Mindwtr 1.3.1

Mindwtr 1.3.1 improves Someday organization, widgets, capture, project follow-ups, local automation, and recovery while making failed writes and background work easier to diagnose.

## Highlights

- Organize one or several Someday tasks into sections with Undo, compact deferred project lists, and area pickers that respect your custom order.
- Android and iOS widgets gain more reliable list navigation, completion Undo, queued-capture refresh, larger Android lists, safer overflow, and better empty-list fallback behavior.
- Save a newly created project follow-up and open it directly for editing. Project keyboard navigation, saved Focus filters, global-search highlighting, and quoted People in Quick Add are more dependable.
- Capture, completion, Focus, restore, and Mind Sweep now surface rejected writes instead of silently continuing. Desktop in-list capture keeps its text when saving fails.
- Sync and storage better preserve archived-project sections and references, referenced attachments, recoverable file generations, and encryption posture while rejecting unsafe managed paths.
- The desktop Local API now covers durable project creation, editing, deletion, restore, and task triage. MCP 1.1.9 strengthens atomic bootstrap, input validation, logging, and protocol-output isolation.
- Mobile adds bulk date pickers and shortcuts, a keyboard-safe checklist preview, Ukrainian, localized help links, version-aware Android system bars, and safer share handoffs.
- Linux notification delivery is awaited through the portal or notification daemon, daily digests remain independent of task reminders, and stable store releases now begin with gradual production rollout.

## Tasks, projects, and Focus

- Move individual or selected Someday tasks between custom sections and undo the change without altering projects, dates, or status.
- Collapse deferred project lists and use compact Someday actions while retaining the full workflow when needed.
- Create a project follow-up with **Save & edit** and open the durable task in the full editor, including its project and section.
- Navigate desktop Projects with the keyboard and return through the project list consistently.
- Saved Focus filters toggle without being deleted, and Focus sections and widget selection share one core derivation.
- Task and bulk-organization area pickers follow the configured area order.
- Global search highlights matching text and tolerates malformed historical assignee values in self-hosted Cloud data.
- Legacy Reference tasks from archived projects are recovered once, while valid archived sections and references remain intact.
- Quoted People in Quick Add accept the repeated opening smart quote macOS can produce while typing, so preview and saved assignment agree.

## Capture, editing, and notifications

- Rejected capture, completion, Focus, restore, and Mind Sweep writes are reported, and a failed desktop in-list capture retains its text.
- Mobile bulk organization adds calendar pickers plus Today and Tomorrow shortcuts for start and due dates.
- Mobile task Preview keeps a newly inserted checklist row visible above the Android keyboard.
- iOS share handoffs are intercepted before page routing on both cold and warm delivery, avoiding an unmatched-route screen.
- Shortcut failure diagnostics remain free of incoming capture content and raw routes.
- Daily morning and evening digests can stay enabled when task reminders are off, and the native alarm map survives an aborted reschedule.
- Linux reminder delivery waits for portal or notification-daemon acknowledgement with a bounded timeout and privacy-safe failure categories.
- Android applies light and dark system-bar styling through the API appropriate for the current OS version.

## Widgets and Apple platforms

- Android widget lists can carry more tasks within the platform parcel budget and route overflow through **View all**.
- Android list choosers open the selected built-in or saved-filter list and follow the active theme.
- Completed widget rows hide after the Undo window, and pending native captures refresh widget data after import.
- Empty Today widgets can refill from Next Actions, while Android and iOS list derivation stays aligned with Focus filters.
- iOS widget navigation, row refill, sizing, snapshot publication, and completion Undo are more consistent.
- iOS adopts scene-based lifecycle delivery and adds durable Siri task-action transport validation.
- Bounded Apple clarification, search, image, and Private Cloud Compute evaluations remain development-only; production and TestFlight builds omit the optional PCC entitlement and UI.

## Sync, storage, and attachments

- Restorable archived projects retain their sections until the project itself can no longer be restored.
- Referenced self-hosted attachments survive orphan cleanup, and older referenced capture recordings remain readable from their historical layout.
- Revoked generated capture credentials stay refused in permissive any-token mode, including after restart.
- File Sync adds privacy-safe failure evidence for attachment uploads while preserving the original recoverable generation.
- Managed attachment paths reject traversal, and sync keeps one encryption-posture decision for the whole cycle.
- Self-hosted audio capture uses the same attachment admission checks as normal uploads.
- Missing and downloading attachments are clearer in the desktop editor.
- The self-hosted connection check uses the configured server instead of accepting a blank or unrelated endpoint.

## Desktop and Local API

- The desktop Local API supports project create, update, delete, restore, and task triage through durable, idempotent transactions.
- Project deletion and restoration preserve the intended child lifecycle without reattaching tasks that were deliberately detached.
- Local API and publication locks recover after a poisoned operation instead of blocking later work.
- Desktop autocomplete keeps its highlighted selection and focus behavior stable.
- Desktop HTTP uses `rustls` 0.23.45, including the fix for [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285.html).

## Self-hosted Cloud, MCP, and automation

- Cloud search ignores malformed historical assignee values while new REST writes reject invalid assignment types.
- Cloud readiness checks are throttled and capture audio follows the normal attachment safety policy.
- MCP keeps core diagnostics on stderr and JSON-RPC protocol messages on stdout.
- MCP database bootstrap is atomic, registered tool schemas validate inputs, and server logs sanitize private fields.
- MCP 1.1.9 includes the release-window fixes and remains usable with local SQLite or self-hosted Cloud backends.
- Documentation clarifies Android local-folder sync and localized help routes.

## Languages, accessibility, and reliability

- Ukrainian is available throughout the app, including Android widget picker labels.
- Documentation links follow the selected app language on desktop and mobile.
- Bulk-organize date controls have accessible names, and translated Someday task-creation labels are reused consistently.
- Mobile retains a bounded, privacy-filtered fatal JavaScript crash record for the next launch.
- Release tests cover failed-write contracts, archive and tombstone migration idempotence, performance-sensitive bulk date controls, and quoted People in project-section Quick Add.

## Distribution

- App Store releases use Apple's phased release, while Google Play and Microsoft Store production releases begin at five percent by default.
- Google Play beta and internal tracks still receive the stable AAB immediately, and release rollouts can be inspected, increased, halted, or completed without rebuilding.
