# Mindwtr 1.3.1-rc.1

This release candidate focuses on safer recovery and more consistent task workflows across desktop and mobile. Please test it with a copy of your normal data and share any failures through in-app Feedback or [GitHub issues](https://github.com/dongdongbh/Mindwtr/issues).

## Changes to verify

- Someday lists support moving one or several tasks between sections, with Undo. Task area pickers follow the custom area order, and the Inbox remains available across area filters.
- Projects support keyboard navigation on desktop. Saved Focus filters toggle without being deleted, global search highlights matching text, and legacy Reference items from archived projects reappear after load.
- Android widgets offer more fixed lists and a clearer list chooser; completed rows hide after Undo and queued captures refresh widget data when the app imports them. iOS widgets improve list navigation, row refill, sizing, and completion Undo.
- Mobile task Preview keeps checklist editing visible above the Android keyboard. Documentation links follow the selected language, and Ukrainian is available throughout the app.
- Sync and storage retain sections of restorable archived projects and referenced Cloud attachments. The self-hosted Cloud serves still-referenced older capture recordings and refuses revoked capture credentials in any-token mode. Desktop File Sync adds privacy-safe diagnostics for attachment upload failures; the underlying upload problem still needs reporter confirmation.
- MCP server diagnostics now go to stderr while protocol messages remain on stdout. Mobile Diagnostics can recover a bounded, privacy-filtered fatal JavaScript crash record on the next launch.
- Desktop HTTP uses `rustls` 0.23.45, which fixes [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285.html) in the TLS dependency.

## Apple evaluation work

The 1.3.1 source adds bounded development evaluations for on-device Inbox clarification, search, and image capture, along with a durable Siri task-action transport and iOS scene-lifecycle validation. The clarification evaluation is enabled only in development builds; device and SDK checks remain pending for the optional Apple paths.

## Testing focus

- Upgrade from 1.3.0; create, edit, complete, cancel, archive, and reopen tasks and projects, then relaunch and sync with another client. Check that Someday section assignment and archived project sections survive.
- On Android, exercise Tasks and Compact widgets, capture from a widget, and edit a checklist in Preview with the keyboard open.
- On iPhone, use widgets and Shortcuts on cold and warm launches; verify a saved action after opening the app. Test Watch capture and Pomodoro on a paired device when available.
- For self-hosted Cloud, read an older audio capture, revoke a capture token, and confirm referenced attachments remain readable after cleanup. For File Sync, retry a failing attachment upload with Diagnostics enabled and share the safe failure marker.
